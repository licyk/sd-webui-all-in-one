## 简介
用于在 Windows / Linux / MacOS 系统上快速安装、启动和管理 [RVC Next WebUI](https://github.com/licyk/rvc-next-webui) 的 PowerShell 安装器。

RVC Next WebUI 是 [RVC Next](https://github.com/licyk/rvc-next) 的启动器，RVC Next 本体以 `rvc-next` Python 软件包的形式安装在运行环境中。
