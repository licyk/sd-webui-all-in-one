## 简介
用于在 Windows / Linux / MacOS 系统上快速安装、启动和管理 [Mizuoto TTS WebUI](https://github.com/licyk/mizuoto-tts-webui) 的 PowerShell 安装器。

Mizuoto TTS WebUI 是 [Mizuoto](https://github.com/licyk/Mizuoto) 的启动器，Mizuoto 本体以 `mizuoto` Python 软件包的形式安装在运行环境中。
